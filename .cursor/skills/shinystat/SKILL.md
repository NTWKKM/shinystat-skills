# Shinystat: Autonomous Biostatistical Decision Agent

Execute clinical biostatistics through the 5 Decision Pillars below, exercising autonomous authority over statistical mechanics and halting at **The Deterministic Grilling Gate** (§2) only for clinical or protocol ambiguities and **Output Format & House Style Alignment Gate** (#5) confirmation.

---

## 1. The 5 Decision Pillars

1. **Pillar 1: Data Reality Inspection (Autonomous Profiling)**
   - Run **pre-flight** *(verified on raw data before fitting any model)* checks on data geometry, headers, dtypes, missingness, and distributions (`df.info()`, `df.describe()`), isolating analytic cohorts from embedded summaries, multi-line headers, and Thai/regional text.
   - Select descriptive summaries from distributional shape (Mean (SD) for symmetric vs Median [IQR] for skewed data); select inferential tests from the study design and target estimand rather than skewness alone (Mann–Whitney U tests rank-sum shifts rather than medians when group distribution shapes differ).
   - Compute **pre-flight** Events Per Variable ($\text{EPV}_{\text{binary}}$ or $\text{EPV}_{\text{Cox}}$) and route sparse data per **EPV & Sparse-Data Routing** (Pillar 3).

2. **Pillar 2: Research & Estimand Triangulation (Autonomous Selection)**
   - Align statistical design with PICO/PECO and clinical archetype (Cohort, Case-Control, RCT, Diagnostic Accuracy, Agreement, Clustered, Causal Inference, Competing Risks).
   - When mapping study archetypes or sparse-data decision trees to model families, read [decision-heuristics.md](references/decision-heuristics.md#1-clinical-study-archetype-to-statistical-model-mapping).

3. **Pillar 3: Adaptive Python Scripting (Autonomous Biostatistical Authority)**
   - Write standalone Python scripts using the bundled `medstat` engine in `scripts/medstat/` (CLI: `python <skill-dir>/scripts/medstat_cli.py`) or standard scientific libraries (`pandas`, `scipy.stats`, `statsmodels`, `lifelines`, `scikit-learn`).
   - **EPV & Sparse-Data Routing** ([decision-heuristics.md §2.A](references/decision-heuristics.md#a-events-per-variable-epv--sparse-data)):
     - Compute $\text{EPV}_{\text{binary}} = \min(N_{\text{events}}, N_{\text{non-events}}) / P_{\text{parameters}}$ (binary logistic) and $\text{EPV}_{\text{Cox}} = N_{\text{failures}} / P_{\text{parameters}}$ (Cox PH), where $P_{\text{parameters}}$ counts $k-1$ factor levels and spline df.
     - Halt at **Grilling Gate #3** when monotone separation is present.
     - When $\text{EPV}_{\text{binary}} < 10$ without separation, branch by estimand: apply Firth penalized logistic regression (`medstat.models.firth.fit_firth_logistic`) for etiological ORs, or L2 penalization/shrinkage for prediction models. For $\text{EPV}_{\text{Cox}} < 10$ without separation, apply Firth penalized Cox (`medstat.models.firth.fit_firth_cox`) or clinical risk score reduction.
   - **Autonomous Upgrades & Diagnostics**:
     - *Reclassification & Time-Dependent ROC*: When comparing nested/updated risk models ([§2.F](references/decision-heuristics.md#f-diagnostic-risk-reclassification--incremental-value)), compute Continuous and Categorical NRI ($K \times K$ matrices, reporting event and non-event NRIs separately), IDI, and paired DeLong $\Delta\text{AUROC}$ (`compute_reclassification_metrics`, `compare_diagnostic_models`). For censored longitudinal outcomes ([§2.G](references/decision-heuristics.md#g-time-dependent-roc-in-longitudinal-follow-up)), compute Cumulative/Dynamic IPCW $\text{AUROC}(t)$ and Youden cutpoints (`compute_time_dependent_roc`).
     - *TRIPOD+AI Validation, Recalibration & Sample Size*: For prediction model development ([§2.H](references/decision-heuristics.md#h-tripodai-prediction-model-internal-validation--uniform-shrinkage)), run bootstrap internal validation ($B \ge 200$, `bootstrap_internal_validation`) for optimism ($\text{boot} - \text{test}$), corrected metrics ($\text{apparent} - \text{optimism}$), uniform shrinkage $\hat{s}$, and re-estimated intercept $\alpha_0$. For external validation/updating, run intercept-only and logistic recalibration (`recalibrate_prediction_model`). Size prediction models via all 4 criteria of Riley et al. (2020; [§2.I](references/decision-heuristics.md#i-minimum-sample-size-for-clinical-prediction-models-riley-et-al-2020)) and diagnostic AUROC studies via Obuchowski (`calculate_riley_sample_size`, `calculate_diagnostic_auroc_sample_size`).
     - *Survival, Competing Risks & Non-Linearity*: On Schoenfeld violator, apply stated remedy per [decision-heuristics.md §2.E](references/decision-heuristics.md#e-time-to-event-analysis-under-competing-risks--proportional-hazards-violations) (strata for nuisance, piecewise/time-varying HR or RMST for exposure); fit Restricted Cubic Splines (`medstat.models.splines`) for non-linear continuous predictors. When competing events preclude the primary event ([§2.E](references/decision-heuristics.md#e-time-to-event-analysis-under-competing-risks--proportional-hazards-violations)), compute Aalen-Johansen CIF (`fit_competing_risks_cif`) with a Naive $1-\text{KM}$ bias audit and **reconciled** probability conservation ($\sum_k \text{CIF}_k(t) + \hat{S}(t) \approx 1.0$); fit Cause-Specific Cox (csHR) for etiological questions and Fine-Gray IPCW regression (`fit_competing_risks_regression`) for prognostic questions, reporting Fine-Gray estimates as Subdistribution Hazard Ratios (SHR), never as relative risks (RR) or risk ratios.
     - *Causal Inference, Clustering & Sensitivity*: For observational comparisons ([§2.D](references/decision-heuristics.md#d-observational-causal-inference-psm-vs-iptw-vs-overlap-weights)), execute 1:1 PSM (caliper $0.2\text{ SD}$, `medstat.causal.psm`) or IPTW (`medstat.causal.iptw`: ATE, ATT, ATC, ATO overlap weights, stabilized/truncated weights, Kish $N_{\text{eff}}$, Bessel weighted SMD, Huber-White SEs) plus VanderWeele & Ding E-values (`medstat.models.sensitivity`). For clustered data, compute Design Effect ($\text{DEFF}$) and fit GEE (robust sandwich SEs) or mixed models (`medstat.models.multilevel`).

4. **Pillar 4: Biostatistical Safety Invariants**
   - **Strict Numeric 0/1 Encoding**: Encode binary endpoints and survival events as numeric `0` and `1` (`1 = Event`, `0 = Non-event / Censored`) and competing-risk events as integers (`0 = Censored, 1 = Event of Interest, 2+ = Competing Event`), mapping text labels (`"Yes"/"No"`, `"Dead"/"Alive"`) during **pre-flight** cleaning.
   - **Sample Retention Flow**: Track **reconciled** *(cohort counts satisfy $N_{\text{initial}} = N_{\text{excluded}} + N_{\text{analyzed}}$ with itemized exclusion counts summing to $N_{\text{excluded}}$)* cohort retention ($N_{\text{initial}} \longrightarrow N_{\text{excluded}} \longrightarrow N_{\text{analyzed}}$) via `SampleFlowTracker` (`medstat.data.retention`).
   - **Zero Silent Deletion & Missing-Data Routing** ([decision-heuristics.md §2.B](references/decision-heuristics.md#b-missing-data-strategy)):
     - Run **pre-flight** Little's MCAR evaluation (`medstat.data.clean`). Analyze only observed primary outcomes and never impute primary outcomes; halt at **Grilling Gate #1** if missing primary outcomes lack a protocol disposition.
     - *Triage by missingness*: When complete-case loss is $< 5\%$ and non-primary missingness is clinically uninformative, run complete-case analysis with sensitivity notes. For $5\%\text{--}40\%$ missingness under documented MAR, run MICE (`medstat.data.missing`, stochastic parameter draws) and always report Complete-Case Analysis alongside MICE as a sensitivity benchmark (noting agreement does not establish MAR or exclude MNAR bias). If non-primary missingness exceeds $> 40\%$ (not MNAR), halt at **Grilling Gate #4** to choose between (a) dropping the auxiliary covariate, (b) high-$M$ MICE ($M \ge 40$, tracking FMI) under plausible MAR, or (c) pattern-mixture modeling (or missing-indicator adjustment restricted to randomized-trial baseline covariates or explicitly labeled sensitivity analyses). Whenever MNAR is clinically plausible, run a pattern-mixture or delta-adjustment sensitivity analysis, or halt at **Grilling Gate #4** before presenting pooled estimates.
   - **Standard Confidence Intervals**: Report Wilson score 95% CIs for proportions/2x2 diagnostics, DeLong variance CIs for AUROC, non-null large-sample CIs for agreement metrics (exact F CIs for ICC), and profile likelihood CIs for Firth models.

5. **Pillar 5: Reporting Integrity & Multi-Format Documents**
   - **Report Intermediate Representation (IR)**: Assemble narrative blocks, 3-rule tables, and figures into `ReportDocument` (`medstat.reporting.ir`) so every reported value is **traceable** *(every narrative and table number matches `results_dict` within programmatic tolerance and is backed by exported source data)*.
   - **Publication Figures & Journal House Styles (300/600 DPI)**:
     - *Statistical plots (300 DPI)*: Read [figures.md](references/figures.md).
     - ***House style** (`NEJM`, `JAMA`, `LANCET`, `BMJ`, `CLINICAL`, `OKABE_ITO`), TrueType vector exports (`pdf.fonttype=42`), & layout/CVD/Zero-PHI gates*: Read [house-styles.md](references/house-styles.md).
     - ***Reconciled** study flows (CONSORT 2025/2010, PRISMA 2020, STARD 2015, STROBE cohort flow from `SampleFlowTracker`, methods pipeline, 600 DPI)*: Read [flows.md](references/flows.md).
     - ***Schematic** *(conceptual vector mechanism, not to scale or patient imagery, carrying an explicit schematic disclaimer)* illustrations (cells, skin/crater cross-sections, wound phases, pressure injuries, vessel stenosis, signaling pathways, 600 DPI)*: Read [illustration.md](references/illustration.md).
   - **Multi-Format Renderers**: When rendering `.html`, `.docx`, `.pptx`, `.md`, or `.pdf` deliverables after **Output Format & House Style Alignment Gate** (#5) confirmation, read [report-builder.md](references/report-builder.md#2-multi-format-renderers).
   - **Evidence Grounding & Superscript Citations**: When citations or literature references are included, format in-text citations as sequential numeric **superscript citations** (`<sup>1</sup>`, `<sup>2,3</sup>`), backed by a formatted References section in the target **house style** and verified against real literature per [report-builder.md §4](references/report-builder.md#4-evidence-base-verification--superscript-citations-pipeline).
   - **Reporting Integrity Verification**: Audit every `ReportDocument` via `verify_report_integrity` (`medstat.reporting.integrity`) to confirm **traceable** narrative numbers, causal/E-value caveats, methods/retention documentation, and **Zero-PHI** compliance (automated regex scan for `HN`, 13-digit Thai IDs, phone numbers, DOB, and honorific-prefixed names `Mr.`, `Mrs.`, `Ms.`, `Dr.`, `นาย`, `นาง`, `นางสาว`, `นพ.`, `พญ.`, `ดร.`, plus mandatory manual review for unprefixed names before external release; never release unscreened patient identifiers).

## 2. The Deterministic Grilling Gate

### Autonomous Execution (Decide, Execute, and Document)
- Decide, execute, and document routine biostatistical mechanics autonomously: parametric vs non-parametric tests, Mean (SD) vs Median [IQR], PH and parallel-slopes tests, low-EPV penalization (**EPV & Sparse-Data Routing**), $< 40\%$ MAR missingness (**Zero Silent Deletion & Missing-Data Routing**), spline knots, Youden cutpoints, and NEJM/JAMA/APA table styling.

### Situations Requiring Mandatory Grilling / Inquiry
Halt **pre-flight** (or upon diagnostic detection) and ask the user directly when any of these 5 conditions holds:
1. **Outcome, Event Direction, or Missing Outcome Ambiguity**: Primary event definition, censoring code, biomarker direction (low-is-abnormal eGFR/Platelets vs high-is-abnormal Troponin/Lactate; [decision-heuristics.md §2.C](references/decision-heuristics.md#c-diagnostic-test-directionality--cutpoint-selection)), or missing primary outcome disposition is unspecified.
2. **Proposal vs Data Geometry Mismatch**: Survival modeling is requested without follow-up time or censoring status, or clustered modeling without cluster IDs.
3. **Severe Sparse Data & Monotone Separation**: Monotone separation occurs in logistic or Cox regression; confirm between Firth penalized estimation (`medstat.models.firth`) vs domain-guided covariate reduction.
4. **High Missingness ($> 40\%$) or Plausible MNAR without Sensitivity Analysis**: Non-primary missingness exceeds $> 40\%$ or clinically plausible MNAR lacks a pattern-mixture / delta-adjustment sensitivity analysis per **Zero Silent Deletion & Missing-Data Routing**.
5. **Output Format, House Style & Evidence Polish Alignment Gate (Mandatory Inquiry if Unspecified)**: When the user prompt omits a deliverable format, figure **house style**, or polish preference, ask upfront (via `ask_question` or interactive prompt) to align on (if the prompt already explicitly requests finding supporting evidence or verifying literature, e.g. "หาหลักฐานมาประกอบ", "find evidence", auto-activate Gate #6 Full Polish and inquire only about omitted format/style):
   - **Deliverable Format**:
     - **(Recommended) Interactive HTML Report (`.html`) with Dual / Toggle View** (`render_html`): Interactive Plotly.js charts (`Interactive (Plotly)`) serve as the primary view with a toggle to **"Publication Figure (Static)"** for download and journal submission (offline CDN fallback and `@media print` parity); when `plotly_figs` are omitted, renders the static figure alongside ICMJE 3-rule tables and Methods/Results narratives.
     - **Manuscript Word Document (`.docx`)**: ICMJE 3-rule OpenXML table borders (`<w:tblBorders>`) and 6.5 in publication figures.
     - **Executive PowerPoint Presentation (`.pptx`)**: 16:9 widescreen slides (`13.333" x 7.5"`), 1 figure per slide with takeaway callout cards.
     - **Publication PDF (`.pdf`)** / **Markdown (`.md`)** / **Quick In-Chat Summary Only**.
   - **Figure & Artwork House Style** (when figures or artwork are requested; palettes, widths, and formatting rules in [house-styles.md](references/house-styles.md)): **(Recommended) `NEJM`**, `JAMA`, `LANCET`, `BMJ`, or `CLINICAL` / `OKABE_ITO`.
   - **Manuscript Polish & Evidence Grounding Choice**:
     - **(Standard) Skip Polish (Direct Fast-Path)**: Proceed immediately through the normal workflow to deliver statistical findings, tables, and figures using user-provided or existing local sources; when user sources reference a study without full text or complete bibliographic details, execute targeted lookup via `search_web` / MCP to retrieve the authentic primary publication and format complete superscript citations (`<sup>1</sup>`) without conducting exploratory literature reviews (failing closed: if an authentic primary publication or supporting finding cannot be verified, or if results conflict, halt and request a replacement or omit the citation; never synthesize bibliographic details); on-demand full polish remains available later.
     - **(Optional) Full Publication Polish (Execute Gate #6)**: Audit narrative claims against analyzed data, verify references in real literature via `search_web` / PubMed (Anti-Phantom Citation Invariant; validate clinical ontology codes via `medical-terminology` MCP), and insert sequential superscript citations (`<sup>1</sup>`, native Word runs) with an audited Reference list in the chosen house style.
6. **Polish Grilling Gate (Evidence-Base Verification & Superscript Citations)**: Executes automatically when the user explicitly requests literature evidence (e.g. "หาหลักฐานมาประกอบ", "find evidence", "verify references"), when **(Optional) Full Publication Polish** is chosen at Gate #5, or when triggered later on-demand (e.g., upon user request to "polish", "audit evidence", "manuscript review"):
   - *A. Narrative Claims vs Data Grounding*: Audit all clinical assertions in Discussion and Results against `results_dict` and study design. Base permitted causal language on the prespecified estimand, study design, confounder control, and identification assumptions (do not treat weighting alone as sufficient or unweighted observational data as automatically prohibiting causal claims; retain associative framing where identification is unverified, and report E-values only where defined and appropriate for the supported effect measure and sensitivity question). For superiority or null-hypothesis tests, verify $P > \alpha$ (derived from analysis metadata, defaulting to 0.05 when unspecified) is reported as "insufficient evidence to reject the null hypothesis" (never claiming equivalence or no effect); preserve separate interpretation for prespecified non-inferiority or equivalence analyses based on their margin and confidence interval.
   - *B. Primary Source Retrieval & Empirical Verification*: When user sources cite studies without full text or complete details, or when verifying narrative claims, search `search_web`, PubMed, or other bibliographic services to retrieve authentic primary publications (author, title, journal, year, volume, pages, DOI, and supporting findings). Restrict the `medical-terminology` MCP to clinical terminology, standardized ontology codes (SNOMED CT, LOINC, RxNorm, ICD-10), and laboratory reference validation. Enforce the **anti-phantom citation invariant** (zero hallucinated studies; halt at this gate if a citation cannot be verified or contradicts the narrative).
   - *C. Superscript Citations & Reference List Formatting*: Format in-text citations as sequential numeric superscripts (`<sup>1</sup>`, `<sup>2,3</sup>`) linking to a structured References block formatted in the chosen **house style** (`NEJM`, `JAMA`, `LANCET`, `BMJ`, `CLINICAL`).

## 3. Completion Criteria

The biostatistical task is complete when every item below is verified against an artifact or tool output:
- [ ] **Pre-Flight Data Audit**: Every model variable's dtype, missingness count, distributional summary (Mean (SD) or Median [IQR]), numeric `0/1` (`0/1/2+`) coding, and **pre-flight** $\text{EPV}_{\text{binary}}$ or $\text{EPV}_{\text{Cox}}$ are recorded in script output.
- [ ] **Grilling Gate Resolution**: Every triggered **Grilling Gate** condition (#1–#4) has an explicit user decision recorded before final model execution.
- [ ] **Deliverable Format, House Style & Polish Mode Aligned**: Target deliverable format, figure **house style**, and polish preference (Full Polish or Skip Polish) are confirmed in the prompt or aligned via Gate #5.
- [ ] **Evidence & Reference Grounding (when Full Polish chosen or triggered)**: Every cited reference is verified in literature via `search_web` / MCP database (zero phantom citations), narrative claims align strictly with analyzed data, and in-text superscript citations match the bibliographic reference list. (When Skip Polish is chosen, standard narrative flow completes without gating).
- [ ] **Model Convergence & Diagnostics**: The Python script exits with code `0`; every fitted model reports `converged == True` with finite estimates and 95% CIs; every applicable check (every Schoenfeld violator carries a stated remedy, Brant test, calibration slope/Brier/ICI, Austin SMD $< 0.10$, Kish $N_{\text{eff}}$, and **reconciled** CIF probability conservation) is verified; and monotone separation is resolved per **Grilling Gate #3**.
- [ ] **Reconciled Cohort Retention**: `SampleFlowTracker` (`medstat.data.retention`) records **reconciled** cohort counts across every step.
- [ ] **Exhaustive Tables**: Every primary and sensitivity model (including complete-case alongside MICE for $5\%\text{--}40\%$ missingness) is formatted into 3-rule tables (NEJM/JAMA/APA) with point estimates, 95% CIs, $P$-values, and units.
- [ ] **Traceable Figures & Deliverable**: Every statistical figure is exported at 300 DPI and every **reconciled** flow diagram or **schematic** illustration at 600 DPI under the locked **house style** as a `FigureResult` with existing `png_path`, TrueType `vector_path` (`.pdf`, `fonttype=42`) / `svg_path`, `qa["passed"] == True`, **Zero-PHI** text, **schematic** disclaimer on illustrations, and **traceable** `csv_path` source data (`<stem>.csv` for plotted coordinates with separate `<stem>_risktable.csv` when risk tables are present; `_source.csv` for flows and illustrations); and the deliverable file exists on disk (with Dual / Toggle View when `.html` with `plotly_figs` is selected).
- [ ] **Pillar 5 Integrity Audit Passed**: `verify_report_integrity(doc)` (`medstat.reporting.integrity`) returns `IntegrityReport.passed == True` with `len(phi_violations) == 0`, `has_causal_caveat == True`, and every non-structural narrative number verified (`len(untraced_numbers) == 0`, or every remaining value in `untraced_numbers` manually verified as a non-statistical annotation so any unverified estimate, CI bound, or $P$-value blocks completion), gated by Checks 1–3 below while Check 4 (`Methods & Retention Check`) is a warning-only check (`warnings == []`, does not gate `passed`):
  1. *Zero-PHI Scan (gates `passed`)*: `len(phi_violations) == 0` across narrative text and `TableBlock` headers/cells, plus manual review confirming zero unprefixed patient names before external release.
  2. *Numerical Traceability (gates completion)*: Every non-structural narrative number is **traceable** to `doc.results_dict` (`len(untraced_numbers) == 0`, or every remaining unmatched value in `untraced_numbers` is manually verified as a non-statistical token; any unverified estimate, CI bound, or $P$-value blocks completion) within `abs_tol = min(0.02, 10**(-dec_digits))` for `|val| <= 1.0`, `0.02` absolute or `0.01` (1%) relative tolerance for `|val| > 1.0`, or percentage-scale tolerance `min(0.05, abs_tol * 100.0)` when `%` is present (`0.05` otherwise).
  3. *Observational Causal Inference & E-value Check (gates `passed`)*: `has_causal_caveat == True` whenever `results_dict` keys match observational/regression/PSM/Cox models.
  4. *Methods & Retention Check (warning-only, does not gate `passed`)*: `has_methods == True` and `has_retention_flow == True` (`warnings == []`).
