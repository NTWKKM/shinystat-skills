## 1. The 5 Decision Pillars (Cloud Sandbox Edition)

1. **Pillar 1: Data Reality Inspection (Autonomous Profiling)**
   - Run **pre-flight** *(verified on raw data before fitting any model)* checks on geometry, headers, dtypes, missingness, and distributions (`df.info()`, `df.describe()`), isolating analytic cohorts from embedded summaries, multi-line headers, and Thai/regional text.
   - Choose descriptive summaries by shape (Mean (SD) symmetric; Median [IQR] skewed) and inferential tests by study design and estimand rather than skewness alone (Mann–Whitney U tests rank-sum shifts, not medians, when group shapes differ).
   - Compute **pre-flight** $\text{EPV}_{\text{binary}}$ or $\text{EPV}_{\text{Cox}}$ and route sparse data per **EPV & Sparse-Data Routing** (Pillar 3).

2. **Pillar 2: Research & Estimand Triangulation (Autonomous Selection)**
   - Align design with PICO/PECO and clinical archetype (Cohort, Case-Control, RCT, Diagnostic Accuracy, Agreement, Clustered, Causal Inference, Competing Risks).
   - When mapping study archetypes or decision trees (§2.A–§2.I) to model families, read [decision-heuristics.md](../_shared/references/decision-heuristics.md#1-clinical-study-archetype-to-statistical-model-mapping).

3. **Pillar 3: Adaptive Standalone Python Scripting (Autonomous Biostatistical Authority)**
   - **Cloud Sandbox Protocol**: Write self-contained Python scripts using standard libraries (`pandas`, `numpy`, `scipy.stats`, `statsmodels`, `lifelines`, `scikit-learn`). When selecting standalone implementations (`Recipe 1`–`Recipe 20`), read the matching recipe file under `references/recipes/` (`01-data-missing-table1.md` through `05-diagnostic-meta-power.md`).
   - **EPV & Sparse-Data Routing** ([decision-heuristics.md §2.A](../_shared/references/decision-heuristics.md#a-events-per-variable-epv-sparse-data--separation)):
     - Compute $\text{EPV}_{\text{binary}} = \min(N_{\text{events}}, N_{\text{non-events}}) / P_{\text{parameters}}$ and $\text{EPV}_{\text{Cox}} = N_{\text{failures}} / P_{\text{parameters}}$ ($P_{\text{parameters}}$ counts $k-1$ factor levels and spline df).
     - Halt at **Grilling Gate #3** when monotone separation is present.
     - When $\text{EPV}_{\text{binary}} \ge 10$ without separation, use `Recipe 10` (multivariable logistic table). If $\text{EPV}_{\text{binary}} < 10$ without separation, branch by estimand: use `Recipe 7` (Firth penalized logistic with profile likelihood CIs) for etiological ORs, or apply L2 shrinkage for prediction models. For $\text{EPV}_{\text{Cox}} < 10$ without separation, apply a scale-aware, data-validated L2-penalized Cox model in `Recipe 11` (standardize continuous predictors and report the transformation, or select and validate `penalizer` on the supported data), or use clinical risk score reduction.
   - **Autonomous Upgrades & Diagnostics**:
     - *Reclassification & Time-Dependent ROC*: When evaluating incremental biomarker value ([§2.F](../_shared/references/decision-heuristics.md#f-diagnostic-risk-reclassification--incremental-value)), use `Recipe 16` for Continuous/Categorical NRI (reporting event and non-event NRIs separately) and IDI, and `Recipe 3` for paired DeLong $\Delta\text{AUROC}$; for censored longitudinal discrimination across horizons ([§2.G](../_shared/references/decision-heuristics.md#g-time-dependent-roc-in-longitudinal-follow-up)), use `Recipe 17` for Cumulative/Dynamic IPCW $\text{AUROC}(t)$.
     - *TRIPOD+AI Validation, Recalibration & Sample Size*: For prediction model development ([§2.H](../_shared/references/decision-heuristics.md#h-tripodai-prediction-model-internal-validation--uniform-shrinkage)), use `Recipe 18` for bootstrap internal validation ($B \ge 200$, uniform shrinkage $\hat{s}$, re-estimated intercept $\alpha_0$) and `Recipe 4` for Brier score, calibration slope/intercept, Austin–Steyerberg ICI, and Vickers DCA; for external model updating, use `Recipe 19` (intercept-only and logistic recalibration); for study sizing ([§2.I](../_shared/references/decision-heuristics.md#i-minimum-sample-size-for-clinical-prediction-models-riley-et-al-2020)), use `Recipe 20` (Riley et al. 2020 4 criteria & Obuchowski 1998 diagnostic AUROC).
     - *Survival & Competing Risks*: On Schoenfeld violator, apply stated remedy per [decision-heuristics.md §2.E](../_shared/references/decision-heuristics.md#e-time-to-event-analysis-under-competing-risks--proportional-hazards-violations) (`Recipe 11`). When competing events exist ([§2.E](../_shared/references/decision-heuristics.md#e-time-to-event-analysis-under-competing-risks--proportional-hazards-violations)), use `Recipe 15` for Aalen-Johansen CIF (with Naive $1-\text{KM}$ bias audit and **reconciled** probability conservation $\sum_k \text{CIF}_k(t) + \hat{S}(t) \approx 1.0$), Cause-Specific Cox (csHR, etiological), and Fine-Gray IPCW regression (prognostic); report Fine-Gray estimates as Subdistribution Hazard Ratios (SHR), never as relative risks (RR) or risk ratios.
     - *Causal Inference, Clustering & Non-Linearity*: For observational comparisons ([§2.D](../_shared/references/decision-heuristics.md#d-observational-causal-inference-psm-vs-iptw-vs-overlap-weights)), use `Recipe 6` for 1:1 PSM (caliper $0.2\text{ SD}$) or `Recipe 14` for IPTW (ATE, ATT, ATC, ATO overlap weights, stabilized/truncated weights, Kish $N_{\text{eff}}$, Bessel weighted SMD, Huber-White robust SEs), plus `Recipe 9` for VanderWeele & Ding E-values. Fit splines for non-linear continuous predictors and `statsmodels` GEE (robust sandwich SEs, $\text{DEFF}$) for clustered cohorts.

4. **Pillar 4: Biostatistical Safety Invariants**
   - **Strict Numeric 0/1 Encoding**: Encode binary endpoints and survival events as numeric `0` and `1` (`1 = Event`, `0 = Non-event / Censored`) and competing-risk events as integers (`0 = Censored, 1 = Event of Interest, 2+ = Competing Event`), mapping text labels (`"Yes"/"No"`, `"Dead"/"Alive"`) during **pre-flight** cleaning.
   - **Sample Retention Flow**: Track **reconciled** *(cohort counts satisfy $N_{\text{initial}} = N_{\text{excluded}} + N_{\text{analyzed}}$ with itemized exclusion counts summing to $N_{\text{excluded}}$)* cohort retention ($N_{\text{initial}} \longrightarrow N_{\text{excluded}} \longrightarrow N_{\text{analyzed}}$) with documented exclusion reasons across every step.
   - **Zero Silent Deletion & Missing-Data Routing** ([decision-heuristics.md §2.B](../_shared/references/decision-heuristics.md#b-missing-data-strategy)):
     - Run **pre-flight** Little's MCAR test (`Recipe 8`; $H_0: \text{MCAR}$, where $p \ge 0.05$ does not prove MCAR or establish MAR). Analyze only observed primary outcomes and never impute primary outcomes; halt at **Grilling Gate #1** if missing primary outcomes lack a protocol disposition.
     - *Triage by missingness*: When complete-case loss is $< 5\%$ and non-primary missingness is clinically uninformative, run complete-case analysis with sensitivity notes. For $5\%\text{--}40\%$ missingness under documented MAR, read [Recipe 12](references/recipes/01-data-missing-table1.md#12-multiple-imputation-by-chained-equations-mice--rubins-rules) for proper Bayesian MICE ($M \ge 5$ for $\le 30\%$ missingness, $M \ge 20$ for $> 30\%$, continuous targets vs type-specific categorical models) and always report Complete-Case Analysis alongside MICE as a sensitivity benchmark (agreement does not establish MAR or exclude MNAR bias). If non-primary missingness exceeds $> 40\%$ (not MNAR), halt at **Grilling Gate #4** to choose between (a) dropping the auxiliary covariate, (b) high-$M$ MICE ($M \ge 40$, tracking FMI) under plausible MAR, or (c) pattern-mixture modeling (or missing-indicator adjustment restricted to randomized-trial baseline covariates or explicitly labeled sensitivity analyses). Whenever MNAR is clinically plausible, run a pattern-mixture or delta-adjustment sensitivity analysis, or halt at **Grilling Gate #4** before reporting pooled estimates.
   - **Standard Confidence Intervals**: Report Wilson score 95% CIs for proportions/2x2 metrics (`Recipe 2`), DeLong CIs for AUROC (`Recipe 3`), exact F CIs for ICC (`Recipe 5`), and profile likelihood CIs for Firth models (`Recipe 7`).

5. **Pillar 5: Reporting Integrity, Publication Figures & Multi-Format Documents**
   - **Figure Generation & Journal House Styles (300/600 DPI)**:
     - *Statistical plots (300 DPI) & Plotly specs*: Read [figures.md](../_shared/references/figures.md).
     - ***House style** (`NEJM`, `JAMA`, `LANCET`, `BMJ`, `CLINICAL`, `OKABE_ITO`), TrueType vector PDF (`pdf.fonttype=42`), & layout/CVD/Zero-PHI gates*: Read [house-styles.md](../_shared/references/house-styles.md).
     - ***Reconciled** study flows (CONSORT 2025/2010, PRISMA 2020, STARD 2015, STROBE cohort flow, 600 DPI)*: Read [flows.md](../_shared/references/flows.md).
     - ***Schematic** *(conceptual vector mechanism, not to scale or patient imagery, carrying an explicit schematic disclaimer)* illustrations (cells, skin/crater cross-sections, wound phases, vessel stenosis, signaling pathways, 600 DPI)*: Read [illustration.md](../_shared/references/illustration.md).
   - **Multi-Format Export**: When assembling `.html`, `.docx`, `.pptx`, `.md`, or `.pdf` deliverables after **Output Format & House Style Alignment Gate** (#5) confirmation, read [report-builder.md](../_shared/references/report-builder.md) so every reported value is **traceable** *(every narrative and table number matches `results_dict` within programmatic tolerance and is backed by exported source data)*.
   - **Evidence Grounding & Superscript Citations**: When citations or literature references are included, format in-text citations as sequential numeric **superscript citations** (`<sup>1</sup>`, `<sup>2,3</sup>`), backed by a formatted References section in the target **house style** and verified against real literature per [report-builder.md §4](../_shared/references/report-builder.md#4-evidence-base-verification--superscript-citations-pipeline).
   - **Integrity Verification**: Run `verify_standalone_integrity` ([report-builder.md §3](../_shared/references/report-builder.md#3-standalone-reporting-integrity-verification)) to confirm **traceable** narrative numbers, causal/E-value caveats, and **Zero-PHI** compliance (automated regex scan for `HN`, 13-digit Thai IDs, phone numbers, DOB, and honorific-prefixed names `Mr.`, `Mrs.`, `Ms.`, `Dr.`, `นาย`, `นาง`, `นางสาว`, `นพ.`, `พญ.`, `ดร.` across narrative text, table headers, and cells, plus manual review for unprefixed names before external release; never release unscreened patient identifiers).

## 2. The Deterministic Grilling Gate

### Autonomous Execution (Decide, Execute, and Document)
- Decide, execute, and document routine biostatistical mechanics autonomously: parametric vs non-parametric tests, Mean (SD) vs Median [IQR], PH and parallel-slopes tests, low-EPV penalization (**EPV & Sparse-Data Routing**), $< 40\%$ MAR missingness (**Zero Silent Deletion & Missing-Data Routing**), spline knots, Youden cutpoints, and NEJM/JAMA/APA table styling.

### Situations Requiring Mandatory Grilling / Inquiry
Halt **pre-flight** (or upon diagnostic detection) and ask the user directly when any of these 5 conditions holds:
1. **Outcome, Event Direction, or Missing Outcome Ambiguity**: Primary event definition, censoring code, biomarker direction (low-is-abnormal eGFR/Platelets vs high-is-abnormal Troponin/Lactate; [decision-heuristics.md §2.C](../_shared/references/decision-heuristics.md#c-diagnostic-test-directionality--cutpoint-selection)), or missing primary outcome disposition is unspecified.
2. **Proposal vs Data Geometry Mismatch**: Survival modeling is requested without follow-up time or censoring status, or clustered modeling without cluster IDs.
3. **Severe Sparse Data & Monotone Separation**: Monotone separation occurs in logistic or Cox regression; confirm between Firth/penalized estimation (`Recipe 7` or scale-aware, data-validated L2-penalized Cox in `Recipe 11`) vs domain-guided covariate reduction.
4. **High Missingness ($> 40\%$) or Plausible MNAR without Sensitivity Analysis**: Non-primary missingness exceeds $> 40\%$ or clinically plausible MNAR lacks a pattern-mixture / delta-adjustment sensitivity analysis per **Zero Silent Deletion & Missing-Data Routing**.
5. **Output Format, House Style & Evidence Polish Alignment Gate (Mandatory Inquiry if Unspecified)**: When the user prompt omits a deliverable format, figure **house style**, or polish preference, ask upfront before finalizing the report (if the prompt already explicitly requests finding supporting evidence or verifying literature, e.g. "หาหลักฐานมาประกอบ", "find evidence", auto-activate Gate #6 Full Polish and inquire only about omitted format/style):
   - **Deliverable Format**:
     - **(Recommended) Self-Contained HTML Report (`generate_html_report`, `.html`) with Dual / Toggle View**: Interactive Plotly.js charts with toggle to **"Publication Figure (Static)"** for submission, ICMJE 3-rule tables, and Methods/Results narratives.
     - **Manuscript Word Document (`.docx`)**: ICMJE 3-rule tables and 6.5 in publication figures (falls back to `.html` if `python-docx` is unavailable).
     - **Executive PowerPoint Presentation (`.pptx`)**: 16:9 widescreen slides (1 figure per slide with takeaway cards, when `python-pptx` is available).
     - **Publication PDF (`.pdf`)** / **Markdown (`.md`)** / **Quick In-Chat Summary Only**.
   - **Figure & Artwork House Style** (when figures or artwork are requested; palettes, widths, and formatting rules in [house-styles.md](../_shared/references/house-styles.md)): **(Recommended) `NEJM`**, `JAMA`, `LANCET`, `BMJ`, or `CLINICAL` / `OKABE_ITO`.
   - **Manuscript Polish & Evidence Grounding Choice**:
     - **(Standard) Skip Polish (Direct Fast-Path / User-Scoped References)**: Proceed immediately through the normal workflow to deliver statistical findings, tables, and figures. References are strictly scoped to user-provided sources: if the user provides no references, omit the external literature References section entirely. When the user provides references (citations, guidelines, paper titles, DOIs, or partial mentions), dynamically adapt search across any available literature/bibliographic MCP servers (e.g. PubMed MCP, PRISMA, NEJM, Cochrane, Semantic Scholar) or `search_web` to retrieve authentic bibliographic details and verify claim support; extract and present real empirical research figures (sample sizes, benchmark effect sizes, control rates, 95% CIs) as comparable only when reported by the source, matching the target estimand, population, outcome, and time horizon, and directly supporting Discussion claims (citing non-empirical sources or sources with different clinical contexts for the claims or criteria they support without inventing or presenting non-comparable figures). When literature services are unavailable, authenticated local full text with source-appropriate bibliographic metadata satisfies verification only when carrying an accepted provenance signal (user-provided file in workspace/prompt, publisher frontmatter/header, or official publication cover; otherwise halt explicitly). Format sequential superscript citations (`<sup>1</sup>`, `<sup>2,3</sup>`) and generate a complete **References** section in the locked **Journal House Style** without conducting exploratory searches for outside/unsolicited papers; on-demand full polish remains available later.
     - **(Optional) Full Publication Polish (Execute Gate #6 / Relevant Literature Enrichment)**: Audit narrative claims against analyzed data, execute the full empirical Discussion grounding, online verification, superscript citations, and House Style References on user-provided sources (adapting to all available literature MCPs), and in addition actively conduct exploratory literature retrieval across available bibliographic MCPs / `search_web` to identify and integrate additional relevant published studies, clinical trials, and guidelines that match the user's research topic. Extract and present real clinical benchmark figures as comparable only when reported by sources, matching the target estimand, population, outcome, and time horizon, and directly supporting specific Discussion claims (otherwise cite without figures or omit), assigning sequential superscript citations (`<sup>1</sup>`, native Word runs) backed by a comprehensive, audited Reference list in the chosen house style (Anti-Phantom Citation Invariant; validate clinical ontology codes via `medical-terminology` MCP).
6. **Polish Grilling Gate (Evidence-Base Verification & Superscript Citations)**: Executes automatically when the user explicitly requests literature evidence (e.g. "หาหลักฐานมาประกอบ", "find evidence", "verify references"), when **(Optional) Full Publication Polish** is chosen at Gate #5, or when triggered later on-demand (e.g., upon user request to "polish", "audit evidence", "manuscript review"):
   - *A. Narrative Claims vs Data Grounding*: Audit all clinical assertions in Discussion and Results against `results_dict` and study design. Base permitted causal language on the prespecified estimand, study design, confounder control, and identification assumptions (do not treat weighting alone as sufficient or unweighted observational data as automatically prohibiting causal claims; retain associative framing where identification is unverified, and report E-values only where defined and appropriate for the supported effect measure and sensitivity question). For superiority or null-hypothesis tests, verify $P > \alpha$ (derived from analysis metadata, defaulting to 0.05 when unspecified) is reported as "insufficient evidence to reject the null hypothesis" (never claiming equivalence or no effect); preserve separate interpretation for prespecified non-inferiority or equivalence analyses based on their margin and confidence interval.
   - *B. Dynamic MCP Discovery & User-Scoped Empirical Grounding*: Dynamically adapt literature retrieval to any available medical/bibliographic MCP servers in the environment (e.g., PubMed, PRISMA, NEJM, Cochrane, Semantic Scholar, medical-terminology), falling back to `search_web` when dedicated MCP tools are unavailable. For every user-provided reference or cited study (even when local full text is provided), query available MCPs or search engines to verify the cited source itself (constructing queries strictly from bibliographic metadata and de-identified descriptors, never transmitting raw clinical notes or PHI), requiring complete bibliographic fields appropriate to the source type: for journal articles, full author list, title, journal, year, volume, and pages (or article number / e-locator when pages are not assigned), and DOI (when assigned); for clinical practice guidelines, consensus statements, government reports, or standards, issuing body/organization, title, year, version/report identifier, and official URL when no DOI exists; and for books or older publications, authors/editors, title, publisher, and year. Verify that the cited source directly supports the Discussion claim. When reported in the source and directly bearing on Discussion claims, extract and present real empirical findings (benchmarks, effect sizes, control event rates) as comparable only when matching the target estimand, population, outcome, and time horizon and directly supporting Discussion claims; cite non-empirical sources (e.g. clinical guidelines, classification criteria) for supported claims without inventing figures. When literature services are unavailable, authenticated local full text with source-appropriate bibliographic metadata satisfies verification only when carrying an accepted provenance signal (user-provided file in workspace/prompt, publisher masthead/frontmatter, or official publication cover); otherwise halt at this gate (anti-phantom citation invariant: zero hallucinated studies).
   - *C. Relevant Literature Enrichment (Full Polish Only)*: When Full Polish is selected or evidence search is explicitly requested, conduct exploratory search across available literature MCPs and `search_web` to identify additional authentic, relevant published studies, clinical trials, or guidelines that directly relate to the study's population, intervention, and outcomes; extract and present real empirical benchmark figures, effect sizes, and control event rates as comparable only when reported by the source, matching the target estimand, population, outcome, and time horizon, and directly supporting a specific Discussion claim (otherwise cite the source for its conceptual claims without figures or omit it).
   - *D. Superscript Citations & Reference List Formatting*: Format in-text citations as sequential numeric superscripts (`<sup>1</sup>`, `<sup>2,3</sup>`) linking to a structured References block formatted in the chosen **house style** (`NEJM`, `JAMA`, `LANCET`, `BMJ`, `CLINICAL`). In Standard Mode, the Discussion incorporates empirical figures when reported and the Reference list contains strictly verified user-provided sources (or is omitted if none provided); in Full Polish, both the Discussion and Reference list are enriched with relevant published literature.

## 3. Completion Criteria

The biostatistical task is complete when every item below is verified against an artifact or tool output:
- [ ] **Pre-Flight Data Audit**: Every model variable's dtype, missingness count, distributional summary (Mean (SD) or Median [IQR]), numeric `0/1` (`0/1/2+`) coding, and **pre-flight** $\text{EPV}_{\text{binary}}$ or $\text{EPV}_{\text{Cox}}$ are recorded in sandbox output.
- [ ] **Grilling Gate Resolution**: Every triggered **Grilling Gate** condition (#1–#4) has an explicit user decision recorded before final model execution.
- [ ] **Deliverable Format, House Style & Polish Mode Aligned**: Target deliverable format, figure **house style**, and polish preference (Full Polish or Skip Polish) are confirmed in the prompt or aligned via Gate #5.
- [ ] **Evidence & Reference Grounding**: Every cited reference is verified through real bibliographic literature via available MCPs/`search_web`, or authenticated local full text with source-appropriate bibliographic metadata and accepted provenance signal when literature services are unavailable (accepting issuing body and official URL/identifier when no DOI exists for guidelines or reports; zero phantom citations; failing closed with an explicit halt if verification is unavailable or conflicting). For each cited source, bibliographic metadata and direct claim support are verified; empirical figures are extracted and presented as comparable only when reported by the source, matching the target estimand, population, outcome, and time horizon, and directly supporting the Discussion claim (sources lacking empirical figures are cited for supported claims without inventing figures); in Standard Mode, references are strictly user-scoped (zero unsolicited external references; bibliographic metadata and claim support are verified, with online comparison against real research data required only when the source reports relevant empirical findings); in Full Polish Mode, the analysis and Reference list are enriched with relevant published studies; narrative claims align strictly with analyzed data, and in-text superscript citations match the bibliographic reference list.
- [ ] **Model Convergence & Diagnostics**: The Python script exits with code `0`; every fitted model reports `converged == True` with finite estimates and 95% CIs; every applicable check (every Schoenfeld violator carries a stated remedy, Brant test, calibration slope/Brier/ICI, Austin SMD $< 0.10$, Kish $N_{\text{eff}}$, and **reconciled** CIF probability conservation) is verified; and monotone separation is resolved per **Grilling Gate #3**.
- [ ] **Reconciled Cohort Retention**: Every analysis step records a **reconciled** `retention_audit` dict.
- [ ] **Exhaustive Tables**: Every primary and sensitivity model (including complete-case alongside MICE for $5\%\text{--}40\%$ missingness) is formatted into 3-rule tables (NEJM/JAMA/APA via `Recipe 13`) with point estimates, 95% CIs, $P$-values, and units.
- [ ] **Methods & Retention Narrative**: Dedicated Statistical Methods and cohort retention flow sections are written in the report narrative.
- [ ] **Traceable Figures & Deliverable**: Every statistical figure is saved at 300 DPI and every **reconciled** flow diagram or **schematic** illustration at 600 DPI under the locked **house style**, with TrueType vector PDF (`fonttype=42`), **Zero-PHI** text, **schematic** disclaimer on illustrations, and **traceable** `_source.csv` coordinates; and the deliverable file exists on disk (with Dual / Toggle View when `.html` with `plotly_figs` is selected).
- [ ] **Pillar 5 Integrity Audit Passed**: `verify_standalone_integrity(narrative_text, results_dict, table_dfs)` (`../_shared/references/report-builder.md §3`) returns `passed == True` (`len(phi_violations) == 0 and has_causal_caveat and traceability_passed`) with every non-structural narrative number verified (`len(untraced_numbers) == 0`, or every remaining value in `untraced_numbers` manually verified as a non-statistical annotation so any unverified estimate, CI bound, or $P$-value blocks completion), gated by its 3 programmatic checks:
  1. *Zero-PHI Scan*: `len(phi_violations) == 0` across narrative text, table headers, and cells, plus manual review confirming zero unprefixed patient names before release.
  2. *Numerical Traceability*: `traceability_passed == True` with `len(untraced_numbers) == 0` (or every remaining unmatched value in `untraced_numbers` manually verified as a non-statistical token; any unverified estimate, CI bound, or $P$-value blocks completion), where every non-structural narrative number is **traceable** to `results_dict` within `abs_tol = min(0.02, 10**(-dec_digits))` for `|val| <= 1.0`, `0.02` absolute or `0.01` (1%) relative tolerance for `|val| > 1.0`, or `0.05` percentage-scale tolerance (`|val - kn * 100.0| <= 0.05`).
  3. *Observational Causal / E-value Check*: `has_causal_caveat == True` whenever `results_dict` keys match observational/PSM/Cox/logistic models.
